# Управление медиа-кэшем

## Обзор изменений

Добавлена возможность просмотра и управления кэшированными медиа-файлами (фото, видео, голосовые сообщения) через интерфейс приложения.

## Новый функционал

### UI изменения

**Настройки → Память**
- Новая кнопка "Просмотреть кэш" открывает менеджер медиа-файлов
- Отображается список всех закэшированных файлов с превью
- Для каждого файла показывается:
  - Превью (миниатюра для фото/видео, иконка для аудио и других файлов)
  - Тип файла (MIME-type)
  - Размер
  - Дата последнего доступа
- Возможность выборочного удаления файлов через чекбоксы
- Кнопки "Выбрать все" / "Снять выделение"
- Счётчик выбранных файлов

### Технические изменения

#### Backend (main process)

**src/main/cache.ts** — MediaCache:
- `list()` — возвращает список всех закэшированных файлов с метаданными
- `delete(keys: string[])` — удаляет выбранные файлы из кэша
- `store()` — теперь сохраняет URL файла в `.url` для последующего отображения

**src/main/main.ts**:
- Новые IPC handlers: `cache:listMedia`, `cache:deleteMedia`

#### Frontend (renderer process)

**src/renderer/settings.ts**:
- `openMediaManager()` — модальное окно с менеджером медиа
- Превью для изображений и видео через `dtmedia://` протокол
- Иконки для аудио и других типов файлов

**src/renderer/util.ts** — новые переводы:
- `viewCache` / `manageMedia` / `cachedFiles`
- `noMediaCached` / `selected` / `deleteSelected`
- `selectAll` / `unselectAll` / `filesDeleted`

**src/renderer/styles.css** — новые стили:
- `.media-manager` — контейнер менеджера
- `.media-toolbar` — панель инструментов
- `.media-list` — список файлов
- `.media-item` — элемент списка с hover-эффектом
- `.file-icon` — иконка для файлов без превью

#### Types (shared)

**src/shared/types.ts**:
- Новый интерфейс `MediaCacheItem`
- Расширен `DtApi.cache` с методами `listMedia()` и `deleteMedia()`

**src/preload/preload.ts**:
- Добавлен bridge для новых IPC методов

## Использование

1. Откройте "Настройки" → вкладка "Память"
2. Нажмите кнопку "Просмотреть кэш"
3. Отметьте файлы для удаления через чекбоксы
4. Нажмите "Удалить выбранные"

Или используйте кнопку "Очистить медиа-кэш" для полного удаления всех файлов.

## Совместимость

- Работает с существующим механизмом кэширования
- URL сохраняется при первом кэшировании файла
- Старые файлы без `.url` отображаются с пустым URL (не влияет на функционал)
- При eviction удаляются все связанные файлы: `key`, `key.type`, `key.url`
